Privacy & accessibility

Local-first by default

DragonForge does not automatically upload support bundles, diagnostic logs, vault contents, recovery packages, credentials, or other private application data. Network activity is limited to features that explicitly require it, such as signed update checks and configured Password Manager synchronization.

Diagnostics privacy

Support diagnostics are redaction-safe and exclude vault contents, credentials, paths, event contents, and security secrets. Export remains an explicit user action.

Accessibility contract

Suite navigation supports keyboard focus, skip-to-content, arrow-key navigation, reduced-motion preferences, Windows forced-colors/high-contrast mode, scalable text, and screen-reader status announcements.

Language readiness

The Phase 23 shared UI layer declares its locale and keeps new suite-shell copy in a string catalog so additional locales can be introduced without changing security logic.
