DragonForge Security Suite

Secure Share

Phase 10 creates offline encrypted .dfshare packages containing recipient-oriented metadata, optional protected secret text, and optional files or folders.

Recipient/sender labels, expiration, secret text, file names, hashes, and file contents are encrypted. Expired packages can still be verified for integrity, but DragonForge refuses to reveal their secret or extract their attachments.

Because the package is an offline file, Phase 10 does not claim remote revocation or reliable open-count enforcement. Those features require an online coordination service and a separate trust model.

Version 0.1.0 · Suite Phase 23 · Security Center is the recommended suite entry point.
