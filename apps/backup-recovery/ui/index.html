DragonForge Security Suite

Backup & Recovery

Phase 9 creates encrypted, authenticated .dfbackup packages for selected suite data and user files. Phase 22 adds encrypted .dfrecovery packages for configuration export/import, full-suite machine migration, versioned recovery-schema migration, conservative state repair, and clean-machine restore drills.

The format is independent from Password Manager and File Vault formats. Backups reject symbolic links and traversal-like paths, use bounded archive limits, and restore through a temporary sibling directory before an atomic-style rename.

Version 0.1.0 · DragonForge 1.0 · Security Center is the recommended suite entry point.
