Integrity Monitor

Phase 7 fingerprints selected Windows startup, persistence, service, scheduled-task, hosts-file, and security-configuration surfaces and compares them against a local baseline.

The baseline stores identifiers and SHA-256 fingerprints, not command contents or monitored file contents. A detected change is evidence for review, not proof of malicious activity.

Phase 18 adds restart-persistent Agent scheduling, a baseline integrity seal, bounded event history, suppression rules, and Security Center alerts. The seal detects unexpected baseline changes but is not claimed to resist an attacker who already controls the same user account and can rewrite all local state.
