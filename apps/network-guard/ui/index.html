Network Guard

Phase 19 extends the existing Windows-first TCP/UDP and DNS visibility with explicit per-application outbound Windows Firewall policy.

Allow/block requests use the exact sibling DragonForge Agent and authenticated privileged service. Rules are scoped to the application path and SHA-256, use a DragonForge-owned rule namespace, and support bounded rollback. Network Guard still does not inspect packet payloads, terminate connections, expose arbitrary firewall syntax, or change unrelated firewall rules.
