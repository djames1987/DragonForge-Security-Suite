# Architecture Decision Records

Use this directory for significant design decisions.

Suggested format:

```text
# ADR-NNN: Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context
## Decision
## Security implications
## Alternatives considered
## Consequences
```

Create an ADR before making difficult-to-reverse choices involving cryptography, IPC, privilege, persistent formats, update signing, plugins, or cross-platform architecture.
