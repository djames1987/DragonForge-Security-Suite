# DragonForge Security Suite v0.1.0-alpha.1

This is the first portable Windows test release of DragonForge Security Suite through the verified Phase 11 baseline.

## Release status

Alpha / external testing only.

The Phase 11 source baseline passed the local Windows verification suite before this release work was prepared. This release is intended to make that suite testable on Windows machines that do not have Rust, Cargo, Node.js, Git, or the source repository installed.

## Included applications

- DragonForge Security Center
- DragonForge Password Manager
- DragonForge File Vault
- DragonForge Authenticator
- DragonForge Security Scanner
- DragonForge Integrity Monitor
- DragonForge Network Guard
- DragonForge Backup & Recovery
- DragonForge Secure Share
- DragonForge Agent

All executables must remain together in the extracted folder because Security Center launches suite components and the Agent by exact sibling path.

## Installation

There is no installer in this alpha.

1. Download DragonForge-Security-Suite-v0.1.0-alpha.1-win-x64.zip.
2. Verify its SHA-256 against the accompanying .sha256 release asset.
3. Extract the entire ZIP.
4. Run Check-Prerequisites.cmd.
5. Launch Launch-Security-Center.cmd.

The test machine does not need a Rust or Node development environment.

## Runtime requirement

The Tauri desktop applications require Microsoft Edge WebView2 Runtime. Most current Windows 10 and Windows 11 installations already include it. The packaged prerequisite checker reports whether it can detect WebView2.

## Security notes

- These binaries are not code-signed yet, so Windows SmartScreen may display an unknown-publisher warning.
- Phase 11 Agent is a normal-user, per-user background process. It is not an elevated Windows service.
- Network Guard remains visibility-only.
- Security Scanner remains read-only.
- Secure Share remains offline and does not provide remote revocation.
- This alpha should not be treated as production security software.
- Avoid using irreplaceable production passwords, recovery codes, OTP seeds, or other sensitive data during early external testing.

## Testing focus

Please test launching Security Center, starting DragonForge Agent, Agent connected/attention state behavior, launching each sibling application, and the normal disposable-data workflows for File Vault, Authenticator, Scanner, Integrity Monitor, Network Guard, Backup & Recovery, Secure Share, and Password Manager.

## Reporting

When reporting a problem, include the release version, BUILD-INFO.txt, Windows version, affected component, reproduction steps, and redacted logs/screenshots. Never include real passwords, recovery codes, OTP seeds, or production secrets.
