# Support

DragonForge Security Suite is an active security-platform project and public portfolio repository candidate. It is not a commercial support service.

For ordinary bugs, documentation problems, or feature ideas, use the repository's GitHub issue templates when issues are publicly available. Include the affected component, commit/version, operating system, reproduction steps, and sanitized logs where useful.

Do not post credentials, Account Secrets, OTP seeds, recovery material, vault contents, tokens, private keys, personal data, or sensitive exploit evidence in public issues. Vulnerabilities belong in the private process described in [SECURITY.md](SECURITY.md).

Unsolicited code contributions are not currently accepted; see [CONTRIBUTING.md](CONTRIBUTING.md).
