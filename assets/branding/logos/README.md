## Usage

- Keep the artwork proportions intact.
- Prefer these files on dark DragonForge surfaces.
- Do not recolor individual product marks outside the suite brand system without updating the brand standard.
- Product icons and smaller square application icons may be derived from the emblem portion when the full horizontal lockup is not appropriate.
- The existing Password Manager logo remains in the Password Manager project until that project is migrated into the suite.
